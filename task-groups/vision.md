## Overview

Start here when the **input is an image or a video** and the output is an understanding of it.

- **Whole-image answers:** a description, an answer to a question, or a class label.
- **Located answers:** boxes around objects, body or object keypoints, pixel masks, per-pixel depth.
- **Making new images or video** is a different job; see the generation group.
