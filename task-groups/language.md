## Overview

Start here when **both the input and the output are text**.

- **Generative tasks** write new text: chat, reasoning, code, tool calling, summarization, translation.
- **Understanding tasks** label or extract from existing text: classification, entity tagging, extractive question answering.
- **Generative models are general**; understanding models are small, fast and cheap for one fixed job.
