## Summary

DeepSeek-R1-Distill-Qwen-32B is a dense language model with 32.8 billion parameters developed by DeepSeek. It was fine-tuned on the Qwen2.5-32B base model using samples generated by DeepSeek-R1. The model supports a context window of 131072 tokens and is released under the MIT License.

## Why It Matters

It outperforms OpenAI-o1-mini across various benchmarks, achieving new state-of-the-art results for dense models.
