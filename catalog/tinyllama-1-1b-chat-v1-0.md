## Summary

TinyLlama-1.1B-Chat-v1.0 is a chat model from the TinyLlama project, a small 1.1-billion-parameter language model. The card says it was fine-tuned from the TinyLlama-1.1B intermediate checkpoint trained for 3 trillion tokens, following Hugging Face's Zephyr training recipe: first on UltraChat dialogues generated by ChatGPT, then aligned on the UltraFeedback dataset with Direct Preference Optimization.

## Intended Use

The card says the model's compactness lets it serve applications that need a restricted computation and memory footprint.

## What Sets It Apart

The card says TinyLlama uses exactly the same architecture and tokenizer as Llama 2, so it can be used in many open-source projects built for Llama. The project's stated aim is to pretrain a 1.1B Llama model on 3 trillion tokens.
